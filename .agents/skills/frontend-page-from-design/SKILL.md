# 依設計稿實作前台頁面

1. 若使用者提供了設計稿路徑，使用該檔案；否則在專案中尋找相關設計稿，例如 `design/`。有多份可能符合的設計稿時，先詢問使用者。
2. 查看設計稿，整理頁面區塊、版面、色彩、字體、圖片和尺寸。若缺少必要資訊，先說明推測或詢問。
3. 查看專案使用的框架、路由方式，以及相關頁面、元件和樣式；依現有慣例決定檔案位置和名稱，不假設每個專案結構相同。
4. 依設計稿實作頁面，建立或修改需要的頁面檔、CSS 樣式檔和路由；適合共用的部分沿用或抽成元件。
5. 只實作設計稿或使用者明確要求的互動；不自行補上未定義的功能。
6. 若能預覽頁面，對照設計稿檢查版面；回報修改檔案，以及實際執行過的驗收和結果。
